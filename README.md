# netflix_dashboard_excel
An interactive Netflix content analysis dashboard made with MS Excel to explore content library and identify trends across movies and shows.

**Features**
1. Analyzed Netflix titles based content type, release year, country, genre and rating.
2. Created KPIs, charts and filters to make dashboard easy to explore.
3. Used Data cleaning, Transformation, Formulas, Pivot tables, and charts to convert raw dataset into meaningful and representable insights.

**Tools Used**
1. MS Excel
2. Pivot Tables
3. Excel Charts and Formulas
